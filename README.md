# StudyDesk Live — Школьная система контроля, QR-посадки и Этюда (19:00–20:30)

Интерактивный цифровой двойник кабинетов школы (классы **7А – 11Б**), двухэтапная система подтверждения присутствия по общему QR-ключу на доске, контроль обязательной вечерней самоподготовки (**Этюд 19:00–20:30**), топ-рейтинг классов и чат отметок учеников вне кабинета.

## Как подключить облачную базу данных (Supabase PostgreSQL)

Чтобы данные хранились не только на вашем ноутбуке, а в облаке (и работали после публикации на GitHub Pages / Vercel с любого телефона или компьютера):

1. Зайдите на [supabase.com](https://supabase.com/) и создайте бесплатный проект.
2. Откройте раздел **SQL Editor** → **New Query**, вставьте содержимое файла [`supabase/schema.sql`](./supabase/schema.sql) и нажмите **Run**.
3. Скопируйте из раздела **Project Settings → API** ваш `Project URL` и `anon public` ключ.
4. Вставьте их прямо на сайте по кнопке **«Подключить БД»** в верхней шапке (или пропишите в `.env` / GitHub Actions Secrets: `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`).

## Запуск локально

```bash
npm install
npm run dev
```
